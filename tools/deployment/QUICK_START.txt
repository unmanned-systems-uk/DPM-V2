🔴 STEP 1: BACKUP (DO THIS TODAY!)
═══════════════════════════════════════════════════════════════════
Run:
  sudo ~/DPM-V2/tools/deployment/backup-air-side.sh

Then:
  # Copy to external USB/SSD
  rsync -av /home/dpm/air-side-backup-* /media/external-drive/

⚠️ DO NOT SKIP THIS STEP - IT'S YOUR SAFETY NET! ⚠️

═══════════════════════════════════════════════════════════════════

🟢 STEP 2: MIGRATION (TOMORROW WHEN NVME ARRIVES)
═══════════════════════════════════════════════════════════════════

OPTION A: SD Card Clone (Faster)
  1. Use Raspberry Pi Imager to clone SD to NVMe
  2. Boot from NVMe
  3. Verify network: ip addr show eth0
  4. Should show: 192.168.144.10/24

OPTION B: Fresh Install (More Reliable - RECOMMENDED)
  1. Flash Raspberry Pi OS to NVMe
  2. Boot from NVMe, complete setup
  3. Run: sudo ~/DPM-V2/tools/deployment/deploy-air-side.sh
  4. Reboot
  5. Restore files from backup
  6. Build Docker container

═══════════════════════════════════════════════════════════════════

🔵 STEP 3: VERIFY (AFTER MIGRATION)
═══════════════════════════════════════════════════════════════════

Network:
  ip addr show eth0            # Should show 192.168.144.10/24
  ping 192.168.144.11         # Test H16 (if powered on)

Docker:
  docker ps                   # Should show payload-manager
  docker logs payload-manager # Should show camera connected

Storage:
  lsblk                       # Should show nvme0n1
  df -h                       # Should show NVMe on /

Camera:
  lsusb | grep Sony          # Should show camera
