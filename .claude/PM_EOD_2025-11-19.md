## 📝 Usage Examples

### Quick Start
```python
from api import DPMController

dpm = DPMController()

# Air-Side
dpm.air_side.connect()
result = dpm.air_side.send_command('camera.capture', {'quality': 95})
dpm.air_side.disconnect()

# Ground-Side
dpm.ground_side.connect()
diag = dpm.ground_side.get_diagnostics()
dpm.ground_side.disconnect()

# SystemTools
logs = dpm.system.query_logs(message_filter='camera', limit=50)
```

### Complete Automated Testing
```python
with DPMController() as dpm:
    # Health check
    health = dpm.multi_domain.run_health_check_workflow()

    # Run capture workflow
    result = dpm.multi_domain.run_capture_workflow(
        quality=95,
        verify_logs=True,
        verify_ground_side=True
    )

    # Export results
    dpm.multi_domain.export_test_results(
        [result.data],
        '/tmp/test_results.json',
        include_logs=True,
        include_analytics=True
    )
```
