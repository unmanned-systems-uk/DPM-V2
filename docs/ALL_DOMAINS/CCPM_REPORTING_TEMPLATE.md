## Usage Instructions

**For PM Role:**
1. Copy this template at session start
2. Fill in sections as you work
3. Post as comment to CCPM Issue #69 at session end (or session start for updates)
4. Include link to any new DPM-V2 docs created

**For CCPM Team:**
1. Review reports for patterns across sessions
2. Ask follow-up questions via Issue #69 comments
3. Use insights to inform CCPM development priorities
4. Validate CCPM features against DPM-V2 pain points

**Report Format:**
- Lightweight for quick sessions (1-2 hours)
- Comprehensive for major sessions (6+ hours)
- Always include metrics and at least one pattern/pain point/automation opportunity

**Frequency:**
- **Minimum:** Session start (brief update on what's happening)
- **Ideal:** Session end (comprehensive report with insights)
- **Critical:** After major discoveries, workflow changes, or issue closures
