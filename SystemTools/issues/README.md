## Issue Status Definitions

- 🔴 **Blocked**: Cannot proceed due to dependencies
- 🟡 **Open**: Ready to be worked on
- 🔵 **In Progress**: Currently being developed
- 🟢 **Review**: Awaiting code review
- ✅ **Completed**: Implemented and merged
- ❌ **Closed**: Won't implement or duplicate

---

## Priority Levels

- **Critical**: Blocks operations, needs immediate fix
- **High**: Important feature or significant bug
- **Medium**: Useful enhancement, non-critical bug
- **Low**: Nice-to-have, minor improvement

---

## Creating a New Issue

1. Copy template from `ISSUE-000-TEMPLATE.md`
2. Name file: `ISSUE-XXX-Short-Title.md`
3. Fill in all sections
4. Update this README with entry
5. Commit to git with `[SYSTEMTOOLS][ISSUE]` prefix

---

## Issue Categories

- **Feature**: New functionality
- **Enhancement**: Improvement to existing feature
- **Bug**: Something broken or incorrect
- **Documentation**: Docs updates needed
- **Performance**: Speed or efficiency improvements
- **UX/UI**: User experience improvements

---

## Cross-Platform Issues

Some issues require coordination with:
- **Air-Side** (Raspberry Pi / sbc/)
- **Ground-Side** (Android app)
- **Protocol** (Communication specs)

These are marked in the issue with integration notes.
